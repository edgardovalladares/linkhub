# LinkHub - Plataforma de Gestión de Servicios Técnicos, Ventas e Inventario

Plataforma profesional para la administración de mantenimientos de videovigilancia CCTV, diagnóstico e inspección de redes, órdenes de trabajo, catálogo de inventario, ventas y emisión de informes de cierre en PDF.

## 🚀 Características
- **Órdenes de Trabajo**: Gestión de mantenimientos técnicos, reparación de redes e instalaciones de equipos.
- **Módulo de Ventas e Inventario**: Registro de ventas con vinculación a órdenes de trabajo y descuento automático de stock.
- **Informes PDF de Cierre**: Formato técnico formal para la entrega de proyectos y mantenimiento.
- **Código QR de Invitación**: Vinculación ágil de colaboradores a la empresa.
- **Modo Oscuro & Adaptación Móvil**: Interfaz fluida y responsive para dispositivos móviles y computadoras.

## 🛠️ Tecnologías
- **Framework**: Next.js 14 (App Router)
- **Lenguaje**: TypeScript
- **Estilos**: Tailwind CSS & Local Fonts (@fontsource/saira & @fontsource/jost)
- **Base de Datos**: Prisma ORM (SQLite en desarrollo / PostgreSQL para producción)
- **Generador QR**: `qrcode.react`
